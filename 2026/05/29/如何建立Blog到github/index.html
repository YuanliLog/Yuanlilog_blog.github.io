blog的开端

开始语

第一次写日志实在大二的时候，那个时候也才知道有github。我的第一篇学习日志写的是C51，奈何GitHub页面的特殊性以及编写确实不太舒服，坚持一周就养老了。如今工作了，总感觉或多或少缺少了点啥。生活不就是点点滴滴的开始吗？所以我也试着开始积累一步一步的遇到的坑，以及找到填埋它的铲。可能走到后面会是许许多多的感概和骄傲吧。所以以此献给我和一起努力的大家。

认识认识

当我学习查阅各种资料时，像视频讲解干货的长视频时，往往评论区里置顶链接传送到github，这种全英文的社区里，虽然现在大多是gitcode或者其它个人的博主自己建立的日志网站。但是github有点像我的白月光，稍有门槛但是旧而忘怀，就像御姐，越老的酒品起来越香。所以我们不过多的讲述这个东东。开始我们正片之旅。

起源

我最初是想自己建立一个网站来写log的不是，就是想白嫖现成，害羞作罢了。目前免费搭建一个属于自己的博客，目前主要是两条路呢：利用 GitHub Pages、Gitee Pages这样的代码托管平台+博客生成框架的方式，他是完全免费且高度自由可以搭配多种工具来编译和使用，缺点就是上手需要命令(编译环境和连接网站的时候就知道error的可怕了)，环境配置，有一定的上手难度;二是使用Wix、WordPress.com还有Blogger这类一站式建站平台，它优点就是零门槛、上手也快。有可视化的拖拽操作、丰富的模板、自带后台。但是缺点也是显而易见，天下哪有免费的午餐：它的免费套餐有存储和功能的限制老生常谈,自定义程度低。

当然啦，既然是开始，就选难的路。极客也不畏惧。所以本次我们采用的是Hexo + GitHub Pages搭建免费博客。

开始的准备工作

软件的下载

开始我们需要安装准备如下三个软件：
1.安装Node.js：它是Hexo的运行环境。[点击此处前往官网]()我们需要下载LTS版本，
下载处会出现两个下载版本：.msi和.zip。新手推荐使用前者，可以自动配置环境变量，自动关联路径，也方便卸载。缺点就是有安装引导非绿色安装较为繁琐。后者呢属于绿色版本，免安装直接解压文件就可以使用了，但是缺点就是需要前往系统环境变量手动进行配置，新手容易出错。卸载时可能geek uninstaller会识别不到不好卸载干净。
2.安装Git：它是用于将博客文件上传到GitHub。[此处前往官网]()，同样默认选项安装。
3.注册GitHub账号：这个在官网右上角sign on选项注册，有的就sign in。注意：一定要记住你自己的用户名，这个后面我们会用到。

后续补充文件夹放置位置(个人喜好)

本地搭建博客

软件下载好，也知道软件存放路径了。我们就开始本地搭建
1.安装Hexo：找到我们存放Node.js的根目录下，我们右键鼠标打开更多显示，选择“Git Bash Here”,输入命令并回车： 

npm install -g hexo-cli

可能会需要个一两分钟哦！
2.初始化博客：继续在Git Bash中依次输入以下命令,xxxblog可以替换成你想要的名字就像我演示的 

hexo init AiKun  
cd AiKun  
npm install

当然肯定会遇到报错我们来依次解决：
3.本地预览：输入以下指令，Ctrl+左键点击出现的：http：//localhost:4000,你就可以看到你的博客雏形！ 

hexo server

(在Git Bansh中按住 Ctrl+C 可以停止预览哦)

将博客发布到GitHub

记住哦~当你在GitHub上仓库建立时选择的是public，那意味着全世界开始关注你了哦
当然建立这一步也很重要：
-在GitHub上创建仓库：登录你的宝贝账号，点击绿色的“New”按键创建一个新的仓库。仓库的命名必须是你的账户用户名+.github.io。创建完后，需要复制此处的仓库地址。例如上述的https://github.com/AiKun/AiKun.github.io.git,如此的格式。
-安装Hexo部署插件：回到我们的Git Bash，确保我们当前路径在我们AiKun文件夹下，我们可以输入命令安装： 

npm install hexo-deploy-git --save

-修改博客的配置文件：在AiKun文件加下我们会找到这么一个文件_config.yml的文件，之时候我们的万能记事本就派上用场了。我们用其打开滑倒文件末尾，找到deploy部分，修改如下格式(注意每一个冒号后面必须要有一个空格这个是语法要求的，绝对不能少)。本人在这一步吃了不少苦头我也会整理我所遇到的坑。 

deploy:   
  type: git  
  repo: 你刚刚复制的仓库地址  
  branch: main

-生成部署博客：
如果到这一步你没有报错，那恭喜你不要高兴的太早接下来才是疑难杂症的开端。真的
我们需要在我们的Git Bash依次执行下面三条指令： 

hexo clean      //
hexo generate   //
hexo deploy     //

我们等待几秒就可以，部署成功后会弹出一个窗口要求你登录GitHub，输入账号和密码即可。进入网站等待几秒连接结束暂时不要关闭弹窗，这时我们的博客就正式上线咯！后续我也会出一章文章补充我们hexo常用的一些命令。这个时候我们初步试试写一篇文章吧。

简述日常写博客的完整流程

以后每次写文章都可以采用这个顺序来做：

建立一篇新的文章

hexo new "文章标题"

执行之后在我们AiKun文件夹目录下，我们的文件会出现在Hexo新建的source/_posts/文件目录下，会生成一个.md的文件。

写文章内容

用任何文本编辑器打开，这里我推荐使用VS Code打开我们的.md文件，接下来使用Markdown语法来写作。这里搞一个简单的文章头部的示例哦。 

---
title:
date:
tags:
categories:
---  

# 这里是正文  

我时长练习两年半的个人偶像练习生，CXK~~我喜欢唱跳，rap，篮球，还有你干嘛！~~。

部署前我们可以本地预览(推荐！)

在发布前我们可以在本地看一下效果： 

hexo clean  
hexo generate 
hexi server

打开即可预览了。

最后部署到GitHub

确认文章没有问题了，执行完整的三步曲： 

hexo clean  
hexo generate 
hexi deploy

或者我们合并成一行： 

hexo clean && hexo generate && hexo deploy

等待几秒钟，看到 INFO Deploy done 或没有报错就算是成功了。

访问我们自己的博客

在浏览器打开我们的仓库链接，有新的文章出现，就说明一切正常，俺们成功了！后面我也会出一章Markdown的常用语法，来熟悉熟悉内容的编写。
